1. Connect your YouTube account

Sign in on Google's own screen. TubeFix never sees your password, and you can revoke access anytime at myaccount.google.com/permissions.

How to get a client ID (about 10 minutes, free)
  1. Go to Google Cloud Console and create a project (any name, e.g. TubeFix).
  2. Left menu → APIs & Services → Library → search YouTube Data API v3 → Enable.
  3. APIs & Services → Credentials → Create Credentials → OAuth client ID → application type Web application.
  4. Under Authorized JavaScript origins, add the address you serve this app from, e.g. http://localhost:8000 (add your live site later the same way).
  5. Copy the client ID it shows and paste it above. For personal use only, the app can stay in Testing mode — no Google verification needed.
